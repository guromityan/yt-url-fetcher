# Quickstart: Using Help

To see the usage instructions for the `yt-url-fetcher` tool:

1. Open your terminal.
2. Run the command with the `--help` flag:

```bash
./yt-url-fetcher --help
```

Or use the short flag:

```bash
./yt-url-fetcher -h
```

You should see a Japanese description of the tool, the available options, required environment variables, and usage examples.
